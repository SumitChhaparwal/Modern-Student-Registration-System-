# Modern Student Registration System

## Project Description
The Modern Student Registration System is a comprehensive website designed to streamline the student registration process. This system provides an efficient and user-friendly platform for managing student registrations. Built with Vanilla JS, it offers a seamless experience for registering students' records.

## Features
- **Modern UI**: Easy-to-use Modern registration interface
- **Form Validation**: That has complete input validation.
- **Adding Record to DataTable**: after entering valid data in the form, we can add a record to the table by clicking on the button
- **Direct Edit & Auto Saving**: With the help of advanced JS, I implemented the feature in which we can directly edit and auto-save all changes to the table.
- **Delete Record**: deleting a record through the delete button on the table
- **Proper Data Backup**: work on local storage to retain data after reload or changing tabs.
- **Responsive Design**: Mobile-friendly interface for accessibility across devices.

## Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript(ES6+)
